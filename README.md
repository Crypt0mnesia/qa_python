# Финальный проект 4 спринта. Тестирование приложения BooksCollector.
Проект содержит тесты для класса BooksCollector, написанные с использованием pytest.
## Структура проекта
 - main.py # Исходный код класса BooksCollector
 - test_book_collector.py # файл с юнит-тестами
 - conftest.py # Файл с фикстурой pytest для создания экземпляра класса
 - .gitignore # Игнорируемые файлы
 - README.md # Документация проекта
## Запуск тестов
````bash
pytest -v test_book_collector.py
````

### Реализованы тесты:
1. test_add_new_book_add_two_books - проверяет добавление двух книг

2. *test_add_new_book_boundary_cases* - проверяет граничные значения длины названия книги (параметризованный тест, проверяет названия длиной 0, 1, 2, 16, 39, 40, 41 символ )

3. test_set_book_genre - проверяет установку жанра книги

4. test_get_book_genre - проверяет получение жанра книги

5. test_get_books_with_specific_genre - проверяет фильтрацию книг по жанру

6. test_get_books_genre - проверяет получение всего словаря книг

7. *test_get_books_for_children_cases* - параметризованный тест, проверяет книги с разными жанрами на включение в детский список

8. test_add_book_in_favorites - проверяет добавление в избранное

9. test_delete_book_from_favorites - проверяет удаление из избранного

10. test_get_list_of_favorites_books - проверяет получение списка избранного

### Соответствие требованиям задания
 - Покрыты все 9 методов класса BooksCollector
 - Написан минимум один тест на каждый метод
 - Есть параметризованные тесты
 - Тесты запускаются и проходят
